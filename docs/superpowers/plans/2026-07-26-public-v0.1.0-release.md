# Public v0.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish v0.1.0 macOS binaries and a Homebrew formula, then validate installation from a clean system.

**Architecture:** A small Go release package owns version metadata, deterministic archive/checksum generation, and formula rendering. A tag-only GitHub Actions workflow runs tests, publishes release assets, and updates the tap using a scoped secret.

**Tech Stack:** Go 1.26, standard library tar/sha256, GitHub Actions, GitHub CLI, Homebrew Ruby formula.

## Global Constraints

- Build only darwin/arm64 and darwin/amd64.
- Publish exact versioned archives and checksums to a GitHub v0.1.0 Release.
- Formula uses immutable release URLs and generated SHA-256 values.
- Homebrew credential is an Actions secret; never print or commit it.
- Publish only after tests/review and finish with a clean-system brew install test.
