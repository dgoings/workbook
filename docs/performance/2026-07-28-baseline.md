## Accepted lower bound

The two SHA-1 harness attempts each used 500 active tasks, exactly 20 operations
per task, one sample, a 60-second per-command timeout, and the `baseline` phase.
Each ran for about 21–22 minutes before aborting. The user accepted **at least
22 minutes** as the current end-to-end lower bound and chose to proceed to
product optimization without another baseline attempt.

This lower bound describes the observed wall-clock harness execution, including
fixture and scenario preparation. It is not a per-scenario latency measurement.
Fixture construction and other setup work would be excluded from the scenario
timings in a completed generated report.
